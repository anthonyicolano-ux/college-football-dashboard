How the rankings work

Raw: ranked by yards allowed per game, lowest first. Efficiency and touchdowns remain separate so you can inspect why a defense ranks where it does.

Adjusted: total actual yards divided by total expected yards, multiplied by 100. Below 100% means the defense allowed less than expected. Expected yards use each opponent’s average in other eligible games through the selected date, excluding its game against this defense. Actual and expected totals must use the same eligible games. Expected production uses completed FBS games available at the last refresh. Adjusted ranks require an expectation for every game in the selected window; partial comparisons show percentages but no adjusted rank.

Rank change: raw rank within the adjusted-eligible pool minus adjusted rank. A positive change means the defense improves after adjustment. Conference and search filters preserve national ranks. Compare uses the same teams for both ranks; its raw rank can differ from the full Raw table. Last Game ranks describe one performance, not season-long defensive quality. Efficiency uses combined yards and attempts; completion percentage uses combined completions and attempts. Ties share a rank.

This version separates opponent adjustment from recency weighting. Last 3 is a separate window; recent games do not receive extra hidden weight. This initial live version includes FBS-versus-FBS games only and shows usable games for opponent baselines. Missing expectations remain unavailable.

About & data sources

Data supplied through CollegeFootballData. Rankings, opponent adjustments and trends are calculated by this dashboard. Only dashboard aggregates are published. No API credentials or raw API responses are included.

Points allowed includes opponent scoring on offense, defense and special teams. Rushing statistics follow source box-score conventions, including sack yardage where applicable. Missing optional statistics appear as —. Last 3 and Last Game use completed games against FBS opponents. Player stats and upcoming matchups are not connected yet.
