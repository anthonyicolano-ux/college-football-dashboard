Reading player usage

Stat games counts games with recorded offensive stats, not confirmed appearances. The selected window uses the team’s last eligible games, so a player who misses the latest game will not appear in Last Game. Per-game values divide by stat games, not team games.

Carry share and reception share compare player and team totals over the same recorded games. They describe usage when offensive stats were recorded, not full-season participation. Rushing attempts follow the source convention, which can include quarterback sacks. A missing category or field is unavailable, not zero. A metric is shown only when that field is present in every recorded game in the selected window.

Targets are shown only if explicitly included in receiving box scores. Target share is unavailable until a complete team-target denominator is verified. No targets are inferred from receptions. Players without a matched QB/RB/WR/TE roster position appear under Other. Snap counts are omitted.

About & data sources

Data supplied through CollegeFootballData. Rates and usage shares are calculated by this dashboard. Only completed FBS-versus-FBS games count, matching Team Defense. Missing values appear as —. API credentials and raw responses stay out of public files.
